# Происхождение и адаптация

Основа: [affaan-m/ECC — security-review](https://github.com/affaan-m/ECC/blob/77cdc456ed9c6be09c1db7186353f4b59af3a778/skills/security-review/SKILL.md), commit `77cdc456ed9c6be09c1db7186353f4b59af3a778`. Исходник изучен 20 ноября 2026 г. Это самостоятельная адаптация, не автоматическая подписка на main; будущие обновления требуют ревью diff.

Сохранены направления: секреты, входные данные/загрузки, инъекции, аутентификация/авторизация, XSS/CSRF, ограничение злоупотреблений, приватность логов и зависимости. Убрана обязательная привязка к Next.js/Supabase/Solana. Вместо универсальных cookie, клиентской проверки MIME и автоматического исправления зависимостей используются условия реального стека и серверные проверки.

Добавлены области OWASP Top 10:2025, границы доверия, изоляция файловой обработки, SSRF, цепочка поставки/CI, обработка исключений, подтверждение находок, принятие некритичных рисков владельцем и протокол свежести pre-merge отчёта. Скрипт и тесты написаны для адаптации; это не сканер ECC.
