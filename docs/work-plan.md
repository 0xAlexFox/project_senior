# План выполнения работ

Версия 1.3 · 25 ноября 2026 г. · Статус: предварительный frontend завершён в IT-0022; серверные задачи остаются в плане.

## Как выполнять

Это единый план: сначала frontend на явно обозначенных тестовых ответах, затем backend и БД, подключение реального API и подготовка выпуска. Здесь объединены последовательность работ и инструкции прежнего каталога `docs/tasks`; отдельные копии задач не ведутся. Идентификаторы TASK-00–06 сохранены для связи с требованиями и историей.

Подготовка frontend ниже является ранней частью TASK-01/02/04/05 и не означает завершения этих задач. Полные задачи выполняются после неё в порядке TASK-00 → TASK-01 → TASK-02 → TASK-03 → TASK-04 → TASK-05 → TASK-06. Условие начала следующей задачи — проверенный результат и журнал предыдущей. Это зависимости будущей работы, а не отметки о завершении.

Текущий прогресс — в [статусе проекта](project-status.md), фактические изменения и проверки — в [истории](history/README.md). После каждого этапа сохранять изменённые файлы, результаты проверок и ограничения. Невыполненную проверку не отмечать успешной. При изменении требований сначала обновлять их источник и зависимые документы по [матрице изменений](../README.md#зависимости-и-изменения).

Восстановление в отдельной среде согласовано по метаданным/файлам; удалённое не воскресает. Проверки пройдены либо незакрытые риски явно блокируют выпуск. Публичный выпуск выполняется отдельным поручением.

### Передача результата

Передать владельцу журнал готовности и эксплуатационные инструкции. Выпуск не входит в эту задачу.
