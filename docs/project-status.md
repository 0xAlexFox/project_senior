# Текущее состояние проекта

Актуализация: 19 ноября 2026 г. Основание: рабочие файлы репозитория, чтение макета через Pixso MCP и сообщение владельца об удалении пустого кадра. Этот документ описывает состояние на указанную дату; его нужно обновлять при следующем изменении состава или стадии проекта.

## Что существует

| Область | Подтверждённое состояние |
| --- | --- |
| Требования | ТЗ версии 0.2, экраны, API/OpenAPI, решения по технологиям, архитектура, модель данных и план приёмки |
| Дизайн | DESIGN.md версии 1.2; тёмная и светлая темы в Pixso |
| Файл Pixso | «конвертер файлов», пять рабочих страниц, 192 кадра: 96 на каждую тему |
| Слои и компоненты Pixso | 7320 слоёв, из них 3638 текстовых; 30 основных компонентов, 674 экземпляра, 16 переменных |
| Исходный пустой кадр | Удалён владельцем после первой отрисовки; не входит в текущий макет |
| Прототипные переходы | Не настроены: при чтении слоёв взаимодействий не обнаружено |
| Git | Ветка `main` существует; работа ведётся в отдельных рабочих ветках по Git-процессу |
| Автопроверка документации | `python3 scripts/verify_docs.py`; работает без `.local/`, макета и внешних Python-пакетов |

Расположение экранов и их идентификаторы: [макет](pixso-mockup.md) и [темы](themes.md). Основная mobile-ширина — 390 px; 430 px — дополнительный вариант главной. Контрольные кадры — 360/768 px и текст 200%.

## Что ещё предстоит

Реализации web/API/worker, базы и миграций, конфигураций запуска и серверной инфраструктуры пока нет. TASK-00–06 — будущие этапы: условия в их разделе «Зависимости и входы» не означают, что предыдущая задача выполнена. Начало реализации — [TASK-00](tasks/00-technical-spike.md).

Реальные вход, конвертация, скачивание, Telegram, переключатель темы приложения, браузерная адаптивность, клавиатура, screen reader, нагрузка и выпуск не проверены. Настройка кликабельного прототипа — отдельная оставшаяся работа. Спецификация и статические кадры не подтверждают работу этих функций.

Выбранные технологии и их версии остаются предложением из [решений по технологиям](04-technology-decisions.md); они не установлены и не испытаны совместно. Совместимость и актуальные патчи следует подтвердить на TASK-00 перед фиксацией зависимостей. При этой актуализации внешний поиск версий и повторная оценка стека не выполнялись.

## Что проверено при актуализации

Проверены имена и локальные ссылки всех отслеживаемых Markdown-документов, структура документации, идентификаторы REQ/AC/TASK и ссылки OpenAPI. Переименование не меняет содержание ТЗ, контракт API или бизнес-правила. Проверка копии только отслеживаемых файлов подтверждает, что `.local/` и личные неотслеживаемые заметки не нужны для перехода по ссылкам.

В Pixso повторно прочитаны страницы, количества слоёв/компонентов/переменных и наличие взаимодействий. Из 24 упомянутых в текущей документации идентификаторов отсутствовал только удалённый пустой кадр; он убран из текущего списка, остальные 23 подтверждены. Макет при этом не редактировался. Геометрические, шрифтовые и визуальные проверки IT-0006/0007 заново не запускались; их результаты сохранены как исторические.

## Исправленные нестыковки

- Текущий состав больше не включает удалённый пустой кадр. У записи о его сохранении в IT-0006 добавлено уточнение о последующем удалении владельцем.
- Удалены текущие инструкции о будущем создании уже существующей `main` и сведения о референсе как части текущего комплекта.
- Описание «будущего макета» заменено на описание созданного дизайна и оставшихся работ. Уточнены 192 кадра / 96 на тему, mobile 390/430 px и 11 именованных адресов плюс 404.
- В TASK-инструкциях завершение предыдущей задачи явно оформлено как условие начала, а не состоявшийся результат.
- Ссылки на исключённые локальные отчёты и личные заметки заменены переносимыми ссылками на журнал/статус либо обычными путями с пометкой «вне Git».
- Переименованы 14 файлов docs и обновлены ссылки; правила имён и различие между текущим статусом и историей закреплены в [навигации](README.md).

Исторические количества слоёв, результаты проверок, ветки и команды не переписаны под сегодняшний результат. Журналы явно отмечены как исторические записи. Подробности аудита и локальных коммитов — [IT-0008](history/IT-0008-documentation-audit.md). Локальный снимок Pixso и машинные отчёты аудита находятся в `.local/docs-audit/` вне Git и не требуются для чтения проекта.
