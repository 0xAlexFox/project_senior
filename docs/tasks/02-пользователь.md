# TASK-02. Пользователь и восстановление доступа

Версия 0.2 · 17 ноября 2026 г. · Статус: инструкция будущей реализации.

## Зависимости и входы

Завершена [TASK-01: Каркас приложения](01-каркас.md); её результат и журнал проверок доступны.

Источники: [ТЗ](../01-техническое-задание.md), [технологии](../04-выбор-технологий.md), [архитектура](../06-архитектура.md), [модель данных](../07-модель-данных.md), [API](../03-api.md), [OpenAPI](../../api/openapi.json), [экраны](../02-экраны-и-сценарии.md), [приёмка](../05-план-и-приёмка.md).

Область требований и проверок: REQ-08–12; AC-18, AC-21–25, AC-27. Числа и правила берутся из ТЗ, контракты — из API/OpenAPI; эта инструкция не вводит новые требования. При противоречии сначала согласовать документы, затем реализацию.

## Работа

Реализовать регистрацию, вход/выход, профиль и настройки с версиями, cookie/CSRF и reauth. Добавить двухстороннюю Telegram-привязку, восстановление, резервные коды, смену пароля и удаление аккаунта. Отзыв доступа оформить общим сервисом для следующих задач.

## Результат

Маршруты пользователя из API §7, сервис авторизации, экраны входа/настроек и интеграционные проверки.

## Критерии завершения

Проверены права владельца, истечение/отзыв сессий, конфликт версий, одноразовость кодов и сбои Telegram. Секреты возвращаются только в разрешённых сценариях.

Сохранить перечень изменённых файлов, фактически выполненные проверки и оставшиеся ограничения. Невыполненную проверку не отмечать успешной.
