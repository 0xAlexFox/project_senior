# TASK-04. Кабинет и внешний API

Версия 0.2 · 17 ноября 2026 г. · Статус: инструкция будущей реализации.

## Зависимости и входы

Завершена [TASK-03: Конвертация файлов](03-конвертация.md); её результат и журнал проверок доступны.

Источники: [ТЗ](../01-техническое-задание.md), [технологии](../04-выбор-технологий.md), [архитектура](../06-архитектура.md), [модель данных](../07-модель-данных.md), [API](../03-api.md), [OpenAPI](../../api/openapi.json), [экраны](../02-экраны-и-сценарии.md), [приёмка](../05-план-и-приёмка.md).

Область требований и проверок: REQ-06/07/12–15; AC-14–20, AC-25/27. Числа и правила берутся из ТЗ, контракты — из API/OpenAPI; эта инструкция не вводит новые требования. При противоречии сначала согласовать документы, затем реализацию.

## Работа

Реализовать библиотеку, поиск, скачивание/удаление, квоту и сохранение снимка настройки. Добавить выпуск/замену/отзыв API-ключа и внешний API поверх общего сервиса задач. Сверить сервер с OpenAPI и подготовить публичную документацию.

## Результат

Рабочие кабинет/библиотека/ключ, внешний API, схемы и примеры без секретов.

## Критерии завершения

Web и API соблюдают одинаковые правила; чужие файлы недоступны; API-ключ показывается один раз. Схемы и примеры formats не содержат удалённых лимитов; квота кабинета независима от входного размера DOCX.

Сохранить перечень изменённых файлов, фактически выполненные проверки и оставшиеся ограничения. Невыполненную проверку не отмечать успешной.
