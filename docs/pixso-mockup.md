# Макет Pixso: тёмная и светлая темы

Дата: 19 ноября 2026 г. Статус: редактируемый визуальный макет в двух темах; кликабельные переходы не настроены.

Текущий состав повторно прочитан через Pixso MCP 19 ноября 2026 г.; [статус проекта](project-status.md). Результаты визуальных и геометрических проверок ниже относятся к указанным итерациям, а не к новому прогону в рамках актуализации документации.

## Где смотреть

Макет создан через подключённый MCP в открытом файле Pixso **«конвертер файлов»**. Это нативные текстовые, векторные и контейнерные слои, компоненты и их экземпляры. Изображения страниц не подставлялись вместо интерфейса. Сам документ хранится в Pixso; Git содержит спецификацию и этот отчёт, а не копию файла редактора.

| Страница Pixso | Состав | Тёмных + светлых кадров |
| --- | --- | --- |
| `00 — Основа` | Палитра, типографика, радиусы, интервалы | 1 + 1 |
| `01 — Компоненты` | Кнопки и состояния, поля, табы, сообщения, переключатели, квота, файлы, загрузка, диалог, навигация | 2 + 2 |
| `02 — Desktop` | Главная, кабинет, файлы, ключ, настройки, авторизация, документация API, конфиденциальность и 404 | 16 + 16 |
| `03 — Mobile` | Те же семейства страниц; основная ширина 390 px, дополнительная главная 430 px, контрольные кадры 360/768 px и текст 200% | 20 + 20 |
| `04 — Сценарии` | Состояния задач, варианты направлений, одноразовые секреты, пустые/ошибочные состояния, диалоги и карта шести потоков | 57 + 57 |

Всего 192 кадра (96 на тему), 30 нативных компонентов, 674 экземпляра компонентов. В коллекции «Конвертер / Тема» созданы 14 цветовых и две BOOLEAN-переменные с режимами «Тёмная» и «Светлая». Светлые варианты находятся справа от исходных на каждой странице и имеют суффикс `· Светлая`. [Расположение, переключение и редактирование тем](themes.md). Внутри форм и карточек используется Auto Layout. Интерфейс — Inter; код — JetBrains Mono, выбранный из доступных моноширинных шрифтов. Используются только искусственные имена файлов и заглушки секретов.

Основные кадры для поиска: главная desktop `4:205`, главная mobile `4:266`, главная 430 px `4:305`, кабинет `4:352`, библиотека `4:815`, API-ключ `4:905`, настройки `4:945`, документация `4:1187`. Карта шести сценариев — `4:3979`. Суффиксы имён кадров в квадратных скобках обозначают их назначение; они не являются частью интерфейса продукта.

В текущем документе только пять перечисленных рабочих страниц. Пустой исходный кадр удалён владельцем после первой отрисовки и не входит в актуальный состав. Упоминание его сохранения в IT-0006 — исторический результат той итерации, см. [уточнение](history/IT-0006-pixso-mockup.md).

## Архив проверки первой отрисовки (IT-0006)

- Повторное чтение документа через Pixso Plugin API подтвердило 5 новых страниц, состав кадров, компоненты и экземпляры.
- Проверены границы всех 3622 созданных слоёв и пересечения соседних элементов внутри Auto Layout: выходов за родительские границы и таких пересечений не найдено.
- Для всех 1819 текстовых узлов проверен `hasMissingFont`: отсутствующих шрифтов нет. Кириллица просмотрена на скриншотах.
- Скриншотами выборочно проверены визуальная система, компоненты, главная, контрольные ширины, текст 200%, формы входа/регистрации/кодов, библиотека, настройки, документация, ключ, готовый результат, квота, потеря сети, диалог удаления и карта потоков. Это выборочный визуальный контроль, а не просмотр каждого из 96 кадров.
- По найденным проблемам исправлены ширина подписей экземпляров кнопок, перенос маски ключа, высота строк действий, отступы, подвал tablet, неподдержанный символ раскрытия и перенос длинного имени при тексте 200%.

Скрипты построения и локальная инвентаризация находятся в `.local/pixso/`, итоговый аудит — `.local/pixso/audit.json`. Они сохранены для диагностики, исключены из Git; повторный запуск построения поверх готового документа без проверки может создать дубликаты.

## Проверка двух тем (IT-0007)

Сохранность 3622 исходных слоёв проверена сравнением до/после: геометрия, тексты, размеры шрифтов и отображаемые тёмные цвета сохранены; градиенты перенесены на два фоновых слоя с управляемой видимостью. Все 96 светлых копий проверены по размерам, внутренней геометрии и содержимому. Для двух главных фреймов проверено переключение режимов в обе стороны, включая градиент.

Итоговый документ содержит 7320 слоёв. Выходов за родительские границы и пересечений соседей Auto Layout не найдено; все 3638 текстовых слоёв прошли проверку `hasMissingFont`. Контраст 24 светлых пар: минимум текста 5.58:1, интерактивных границ 3.31:1. Выборочно просмотрены скриншоты главных, компонентов, входа, файлов, настроек, mobile 430/360 px, ошибки и диалога удаления. Это не визуальный просмотр всех 192 кадров и не проверка работающего приложения.

Исходный снимок, чтение результата, скрипты и отчёты темы находятся в `.local/light-theme/` вне Git; итог — `verification.json` и `layout-audit.json`. Скрипты изменения документа не предназначены для повторного запуска поверх готового результата. Подробности — [темы](themes.md) и [IT-0007](history/IT-0007-light-theme.md).

## Ограничения

Два проверочных варианта записи реакции клика через доступный Plugin API не сохранились: чтение `reactions` вернуло пустой массив, метод `setReactionsAsync` отсутствует. Поэтому интерактивный прототип не объявляется созданным. Шесть сценариев представлены отдельной визуальной картой и соответствующими кадрами; настройка кликабельных переходов остаётся следующим этапом.

Макет не проверяет реальный вход, конвертацию, скачивание, буфер обмена, сеть и Telegram. Статические кадры 360/768 px и текст 200% не заменяют браузерную проверку адаптивности, клавиатуры, screen reader и доступности готового приложения. До реализации также требуется дальнейшее уточнение визуального результата владельцем.
