# Первая визуальная версия макета Pixso

Дата: 19 ноября 2026 г. Статус: редактируемый визуальный макет; кликабельные переходы не настроены.

## Где смотреть

Макет создан через подключённый MCP в открытом файле Pixso **«конвертер файлов»**. Это нативные текстовые, векторные и контейнерные слои, компоненты и их экземпляры. Изображения страниц не подставлялись вместо интерфейса. Сам документ хранится в Pixso; Git содержит спецификацию и этот отчёт, а не копию файла редактора.

| Страница Pixso | Состав | Кадров верхнего уровня |
| --- | --- | --- |
| `00 — Основа` | Палитра, типографика, радиусы, интервалы | 1 |
| `01 — Компоненты` | Кнопки и состояния, поля, табы, сообщения, переключатели, квота, файлы, загрузка, диалог, навигация | 2 |
| `02 — Desktop` | Главная, кабинет, файлы, ключ, настройки, авторизация, документация API, конфиденциальность и 404 | 16 |
| `03 — Mobile` | Те же семейства страниц; главная 430 px, контрольные кадры 360/768 px и текст 200% | 20 |
| `04 — Сценарии` | Состояния задач, варианты направлений, одноразовые секреты, пустые/ошибочные состояния, диалоги и карта шести потоков | 57 |

Всего 96 кадров, 30 нативных компонентов, 322 экземпляра компонентов. Внутри форм и карточек используется Auto Layout. Интерфейс — Inter; код — JetBrains Mono, выбранный из доступных моноширинных шрифтов. Используются только искусственные имена файлов и заглушки секретов.

Основные кадры для поиска: главная desktop `4:205`, главная mobile `4:266`, главная 430 px `4:305`, кабинет `4:352`, библиотека `4:815`, API-ключ `4:905`, настройки `4:945`, документация `4:1187`. Карта шести сценариев — `4:3979`. Суффиксы имён кадров в квадратных скобках обозначают их назначение; они не являются частью интерфейса продукта.

Исходная страница и пустой кадр `iPhone 14 & 15 Pro Max` (`2:1`, 430×932 px) сохранены без изменения содержимого и размеров.

## Что проверено

- Повторное чтение документа через Pixso Plugin API подтвердило 5 новых страниц, состав кадров, компоненты и экземпляры.
- Проверены границы всех 3622 созданных слоёв и пересечения соседних элементов внутри Auto Layout: выходов за родительские границы и таких пересечений не найдено.
- Для всех 1819 текстовых узлов проверен `hasMissingFont`: отсутствующих шрифтов нет. Кириллица просмотрена на скриншотах.
- Скриншотами выборочно проверены визуальная система, компоненты, главная, контрольные ширины, текст 200%, формы входа/регистрации/кодов, библиотека, настройки, документация, ключ, готовый результат, квота, потеря сети, диалог удаления и карта потоков. Это выборочный визуальный контроль, а не просмотр каждого из 96 кадров.
- По найденным проблемам исправлены ширина подписей экземпляров кнопок, перенос маски ключа, высота строк действий, отступы, подвал tablet, неподдержанный символ раскрытия и перенос длинного имени при тексте 200%.

Скрипты построения и локальная инвентаризация находятся в `.local/pixso/`, итоговый аудит — `.local/pixso/audit.json`. Они сохранены для диагностики, исключены из Git; повторный запуск построения поверх готового документа без проверки может создать дубликаты.

## Ограничения

Два проверочных варианта записи реакции клика через доступный Plugin API не сохранились: чтение `reactions` вернуло пустой массив, метод `setReactionsAsync` отсутствует. Поэтому интерактивный прототип не объявляется созданным. Шесть сценариев представлены отдельной визуальной картой и соответствующими кадрами; настройка кликабельных переходов остаётся следующим этапом.

Макет не проверяет реальный вход, конвертацию, скачивание, буфер обмена, сеть и Telegram. Статические кадры 360/768 px и текст 200% не заменяют браузерную проверку адаптивности, клавиатуры, screen reader и доступности готового приложения. До реализации также требуется дальнейшее уточнение визуального результата владельцем.
