# IT-0013 — пополнение памятки после значимых тем

Дата: 20 ноября 2026 г.
Поисковые слова: обучение, памятка, значимая тема, локальное правило, AGENTS.

## Задача и результат

По запросу владельца в AGENTS.md текущего проекта добавлено обязательное пополнение [памятки нового web-проекта](../../заметки/подготовка-нового-web-проекта-с-codex.md) после значимых тем до итогового отчёта и коммита итерации. Определены критерии значимости, состав записи, проверка актуальности уже описанных тем и указание обновлённого раздела в отчёте. Предусмотрены обновление существующего текста без дублирования, разделение проверенных выводов и гипотез, исключение секретов и частных параметров.

В памятке дополнен раздел 8 «Что будем дополнять по мере обучения», версия повышена до 0.5, журнал обновлён. Правило ограничено project_senior; глобальные инструкции, установленные навыки и правила других проектов не изменялись. Само наличие памятки не означает автоматического переноса локального правила в новые проекты.

Фактические результаты сохраняются локально в `.local/learning-notes-rule/`. Python-инструмент, приложение и Pixso не меняются; их тесты/сборка и проверка редактора для этого изменения не требуются.
