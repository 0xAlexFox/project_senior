# IT-0018 — Целевое ревью безопасности формы входа

Дата: 24 ноября 2026 г. Навык: `project-security-review`.

## Объём и границы доверия

По поручению владельца проверены `/auth/login`, LoginForm, LoginPage, FormField, NoticeMessage, BaseButton, маршрутизатор, layout, web-конфигурация, manifests/lock и связанные браузерные тесты. Это целевой аудит текущей страницы, не полный аудит проекта и не pre-merge квитанция для всего diff frontend. Серверная авторизация отсутствует: форма валидирует ввод и показывает заглушку, не создавая сессии и не отправляя credentials.

Активы — пароль, логин и выбранный File, показываемый на странице входа. Входы — поля, имя файла и query маршрута. Проверены пути к DOM, памяти компонента, сети, URL, storage, cookies и консоли. Пароль остаётся в памяти формы; очистка поля не является доказанным стиранием памяти браузера. Внешние документы/строки не исполняются как инструкции.

## Дополнительные изменения

Для показанного пароля (`type=text`) явно заданы spellcheck=false, autocorrect=off и autocapitalize=none; autocomplete=current-password сохранён. Это усиление конфиденциальности, а не заявление о воспроизведённой отправке данных службе правописания. Атрибуты — указания браузеру; поведение внешних расширений и онлайн-проверки ОС не тестировалось. После отправки заглушки пароль очищается и снова скрывается.

Ошибки связаны с полями и теперь появляются также после ухода из изменённого поля, как задано сценариями. При переходе к кнопке проверка откладывается до её действия/ухода из группы поля, чтобы вставка сообщения не сдвигала кнопку между mousedown и mouseup. Полный промежуточный прогон выявил этот регресс фокуса, он исправлен; отдельный тест проверяет показ/скрытие короткого пароля при появлении ошибки.

## Проверки и результат

Итог: PASS в указанном frontend-объёме, подтверждённых нерешённых находок нет.

- `npm run test:e2e` — 36 passed, один worker: 26 целевых сценариев входа и 10 прежних регрессионных.
- `npm run check` — PASS: документация, дерево зависимостей, формат настроек/web/тестов.
- `npm run build:web` — PASS.
- `npm run audit:dependencies` — 0 уязвимостей по текущему ответу npm registry. Manifests/lock не изменялись; версии Vue/Router/Vite/Playwright сверены с lock, embedded usernames в resolved URLs не обнаружены.
- Целевой статический просмотр — без request/persistence sinks, динамического HTML/исполнения и backend-импортов; в bundle отсутствуют серверные имена секретов и тестовый секрет. Это не полный автоматический поиск утечек.
- Скриншоты: исходная форма desktop 1440 px dark и mobile 390 px light, ошибки на 360 px light и dark с текстом 200%. HTTP 200, корректные title/H1, осмысленное содержимое, без framework overlay, горизонтального overflow и ошибок/предупреждений приложения. Фокус ошибки виден, подписи читаются, кнопки доступны. Файлы и evidence.json — `/tmp/senior-login-security-qa/`, вне Git.
- Переносимая копия только отслеживаемых файлов без .local — PASS: 45 Markdown, 241 локальная ссылка/якорь, 3 JSON-примера, 60 $ref. Staged-содержимое сверено с проверенными файлами, `git diff --cached --check` — PASS. Затронутые проверки выполнены на синтетических данных через Playwright в Chrome; Browser plugin отсутствует, IAB ранее оказался недоступен. Использован уже существовавший до итерации сервер на 127.0.0.1:5173 (PID 18863); его принадлежность не менялась и остановка не выполнялась. Новые серверы для этой проверки не запускались.

Не проверялись: работающая авторизация, сетевой перебор/блокировки, enumeration аккаунтов, CSRF, серверные cookies, Argon2id, recovery, физические устройства, Safari/Firefox, screen reader, онлайн-служба проверки орфографии и история секретов всего репозитория. Эти ограничения не снимают обязательные backend-контроли перед выпуском.
