# IT-0020 — Семантическая форма конвертера

Дата: 25 ноября 2026 г.

## Задача и реализация

По поручению владельца семантика form и обработчик submit добавлены сейчас, до backend. ConverterCard сохраняет класс, палитру, содержимое и композицию; section заменён на form с novalidate и @submit.prevent. Вместо активной ссылки/неактивной кнопки используется единая кнопка type=submit с disabled по canContinue. Обработчик повторно проверяет canContinue и выполняет router.push на константный `/auth/login`; прежнее хранение File в памяти и поведение reload сохранены. Вспомогательные кнопки остаются type=button. Нативная отправка файла, FormData/backend-конвертация и сессия не добавлены.

Контрольный сценарий: главная → выбор корректного файла → кнопка или Enter/Space → форма входа с тем же File. Отсутствующий/некорректный файл не разрешает переход даже через requestSubmit и снятый вручную disabled. Старые тесты обновлены под роль button; добавлены четыре сценария новой формы.

Документация Vue/Router прочитана через Context7: для Router 4.6.5 выдана ближайшая 4.6.4, для Vue 3.5.46 — текущая документация. Использованы useRouter/router.push и @submit.prevent. Зависимости и API-контракт не изменялись.
