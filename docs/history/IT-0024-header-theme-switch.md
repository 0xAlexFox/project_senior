# IT-0024 — Переключатель темы в шапке и Pixso

Дата: 27 ноября 2026 г. Основание: владелец поручил заменить select на солнце/луну по приложенному референсу, разместить слева от действий шапки, сохранить приоритет ручного выбора и добавить компактный возврат к ОС, обновить сам макет Pixso.

## Изоляция и решение

Режим Б, один исполнитель без субагентов, продолжение своей `feature/frontend-completion` от `97bac83`; target `main`. Исходное дерево/индекс чистые, работа в project_senior. Разрешения на merge/push нет. Новый UI — нативная кнопка role=switch «Тёмная тема» с солнцем/луной и движущейся подложкой, рядом details со стрелкой и «Следовать системе». Сохраняется существующий ранний bootstrap и единственный несекретный ключ converter.theme. Режимы и синхронизация не зависят от учебного входа.

Блок 132×44 px: основная кнопка 88×44, дорожка 80×40, стрелка 44×44. Иконки 20 px, stroke 1.5. Использованы существующие семантические цвета. Ползунок 180 мс; reduced-motion отключает движение. До 420 px у бренда остаётся знак с доступным именем; это намеренное отличие от прежней шапки ради одной строки. При отказе storage открывается пояснение; listener для закрытия вне компонента снимается на unmount. Escape возвращает фокус стрелке; выбор ОС закрывает меню с возвратом фокуса, переход и уход фокуса закрывают меню.

## Pixso

В списке инструментов Pixso отсутствовал, поиск плагина не дал результатов. Через нативный редактор подтверждены открытый файл «конвертер файлов», зелёные индикаторы MCP/облака. Настроенный локальный endpoint фактически ответил на initialize/tools-list/fetch_context (16 переменных, 17 стилей, 30 прежних компонентов). Использован его документированный eval_script через локальный клиент, без изменения настроек MCP.

До записи сохранена геометрия исходных шапок. Добавлены четыре нативных компонента: ThemeSwitch/dark `32:749`, light `32:772`, ThemeMenu/dark `32:758`, light `32:781`. Две доски-образца `32:745` и `32:768` находятся ниже прежних на «01 — Компоненты». Цвета привязаны к существующим переменным. Во всех 144 настоящих шапках (32 desktop, 40 mobile, 72 сценария) — ровно один экземпляр слева от действия. Два отдельных кадра мобильной навигации не являются шапками и не менялись.

Повторное чтение подтвердило 5 страниц, 194 кадра, 34 компонента, 818 экземпляров. Размеры и позиции исходных шапок/действий сохранены; изменены только видимость подписи/позиция знака у узкого бренда и ширина текстовых границ подписи 430 px (130→96). Снимки обеих досок и mobile-шапки просмотрены. Нативный редактор показал обновлённую главную/вход и зелёный индикатор сохранения. Кликабельные переходы Pixso не добавлялись; полный визуальный аудит всех кадров не заявляется.
