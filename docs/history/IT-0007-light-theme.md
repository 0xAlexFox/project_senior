## Задача и решение

По прямому запросу владельца добавлена светлая тема в существующий макет «конвертер файлов» и документацию проекта. Создана коллекция «Конвертер / Тема»: 14 COLOR-переменных и две BOOLEAN с режимами «Тёмная» / «Светлая». Сплошные заливки и обводки связаны с семантическими цветами; градиент главной реализован двумя фоновыми прямоугольниками, видимость которых зависит от режима. Светлая тема имеет собственные контрастные оттенки ошибок и предупреждений, графитовую основную кнопку и мягкий персиково-синий градиент.

Для каждого из 96 исходных кадров создан светлый вариант справа на той же странице. Всего 192 кадра, 30 общих основных компонентов и 674 экземпляра. Светлые доски компонентов используют экземпляры исходных компонентов; основные компоненты не дублировались. Содержимое обычных копий экранов редактируется отдельно, цветовые переменные общие.

Сначала Plugin API отклонил обращение из режима разработчика. Владелец переключил редактор в режим дизайна. `write_variables` создал коллекцию, но отклонил тип `COLOR` при создании переменных; переменные успешно созданы через `pixso.variables` в `eval_script` с повторным чтением результата. Вызов `createPage` был отклонён редактором; подтверждено отсутствие частичных изменений после отката, варианты размещены на существующих страницах. Причина отказа создания страницы не установлена. Эти ограничения не помешали добавлению тем.
