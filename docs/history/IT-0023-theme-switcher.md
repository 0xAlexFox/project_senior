Исходный HEAD `32ecc1dc9966d2a03c964346995f3554015bc6d7`, target `main`; IT-0022 ещё не интегрирован. Дерево/индекс до правок чистые. Backend, зависимости и макет Pixso не меняются; разрешения на merge/push нет.

## Реализация

Нативный подписанный select «Тема оформления» виден справа под шапкой на всех страницах, включая auth и mobile. По умолчанию «Системная» следует ОС в реальном времени. Явные light/dark имеют приоритет, сохраняются только в собственном `localStorage['converter.theme']` и синхронизируются между вкладками. Возврат к системной удаляет только этот ключ. Выбор независим от учебного режима/выхода.

Маленький внешний classic-script из public применяется до стилей/запуска Vue; inline script, eval и сторонних библиотек нет. CSS использует прежние палитры, выбранные allowlist-атрибутом корня. Root-composable подписывается на media/storage и снимает обработчики при unmount. При недоступном хранилище UI работает в памяти, после ручного выбора объясняет, что сохранение не удалось. Неизвестное значение игнорируется, не вставляется в HTML.

В headless Chrome/macOS системный popup select не управляется комбинацией Space/ArrowDown: проверены реальный Tab-фокус и выбор штатным selectOption; физическое управление OS-popup не объявляется проверенным. URL main в раннем тесте учитывает HMR query.
