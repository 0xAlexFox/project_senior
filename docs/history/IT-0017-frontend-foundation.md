## Реализация

Vue/Vue Router/Vite использованы из существующих зависимостей. Добавлены app/main/router/layout, страницы главной и входа, features auth/conversion, общие Button/Field/Notice/Icon и семантические токены двух тем. Темы следуют ОС; отдельного переключателя и хранения предпочтения нет. Inter с кириллицей и OFL-лицензией размещён локально из официального каталога Google Fonts; SVG-пути перенесены из Pixso без замены геометрии.

Главная: выбор/замена/удаление одного файла, drag-and-drop, три направления, предупреждения, клиентские UX-проверки расширения/MIME/размера, сохранение File в памяти между SPA-переходами. Reload сбрасывает файл. Конфигурация форматов — явный локальный placeholder для будущего GET /api/app/formats, идентификаторы совпадают с контрактом. Байты не отправляются и не проверяются движками; клиентская проверка не является защитой backend.

Вход: пустые поля, валидация после отправки, показ/скрытие пароля, доступные подписи и ошибки, сообщения заглушки. Нет fetch, cookies, записи credentials в URL/storage и имитации успешной сессии. После отправки пароль очищается. Остальные маршруты показывают явные заглушки, неизвестный адрес — 404. Корневой .env не загружается web-конфигурацией.

Обновлены статус, единый план, границы AGENTS, архитектура, инструкции запуска/проверки и ссылки на фактическую готовность. TASK-00–06 целиком не завершены; ограничения пунктов frontend перечислены в статусе.
