## Пункт 7 — главная и форма трёх направлений

Форма использует конфигурацию учебного API с отменой устаревшего чтения, состоянием загрузки/ошибки и повтором. В учебном кабинете виден подтверждённый флаг сохранения; submit создаёт только синтетический job и блокирует повтор/смену файла. Развёрнутые состояния задачи — следующий пункт 8.

Исправлен отказ для application/octet-stream: по ТЗ это допустимая MIME-подсказка, окончательная проверка байт нужна серверу. Неизвестное направление даёт ошибку без падения/потери файла. Размеры меньше KiB показаны в байтах с русским склонением вместо округления до нуля. Выход из учебного кабинета очищает локальный File/job; поздний ответ защищён epoch, принятая синтетическая задача адаптера не отменяется.
