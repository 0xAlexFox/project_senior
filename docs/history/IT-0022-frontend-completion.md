Границы доверия: пользовательские поля и File остаются недоверенными; демонстрационные ответы никогда не выдаются за реальную сессию/обработку. Пароли/коды/полные ключи не отправляются и не записываются в storage/URL/логи. Тестовый кабинет включается явно отдельным действием, не успешным сообщением настоящей авторизации. Результат скачивания может быть только явно учебным артефактом; выбранные байты не преобразуются браузером под видом серверной конвертации. Сроки/квоты/Unicode — по ТЗ, дата на границе интерфейса по выбранному часовому поясу, по умолчанию Europe/Moscow.

Проверка пункта: сопоставлены карта адресов, состояния и перечень компонентов; документационный валидатор и diff проверяются перед коммитом. Новая сборка не нужна: исходники приложения не менялись. Памятка: существующие разделы 4.3/4.4 и 5.2 актуальны, искусственная новая запись не добавлена.
