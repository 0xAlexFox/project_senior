# IT-0021 — ESLint, Stylelint и Ruff в общей проверке

Дата: 25 ноября 2026 г.
Поисковые слова: линтер, ESLint, Vue, Stylelint, Ruff, границы импортов, clip-path.

## Задача и решение

По поручению владельца внедрены рекомендации исследования линтеров. Ранее ESLint/Vue-плагин были установлены без конфигурации, а check проверял документацию, зависимости и форматирование. Теперь `npm run check` дополнительно запускает все три линтера; отдельные команды позволяют проверять JS/Vue, CSS и Python. Автоисправления выполняются только явной командой `npm run lint:fix`, с последующим просмотром diff. Форматирование остаётся у Prettier.

ESLint: JS recommended, Vue essential, строгие сравнения, const/no-var, запрет eval/Function/v-html, console в коде приложения и неиспользуемых отключений правил. Намеренно неиспользуемые имена с `_` допускаются; используемое имя с таким префиксом отмечается. Vue recommended целиком не включён: исследование показало только 15 дополнительных замечаний о порядке атрибутов. Окружения браузера, Node-конфигураций и Playwright разделены; для тестовых файлов совмещены globals из-за browser-callbacks.

В исходниках frontend запрещены статические импорты Node built-ins (обычные и node:-имена), серверных workspaces и прямых файлов backend/conversion/API/worker. Contracts разрешены. Правило распространяется также на MJS/CJS-файлы, а не только текущие JS/Vue. Динамические загрузки и транзитивные зависимости требуют отдельного контроля.

Stylelint 18.1.0 с config-recommended 19.1.0 проверяет ошибки отдельных CSS-файлов без ограничений специфичности, размеров и !important. Он обнаружил устаревшее clip в sr-only: заменено на clip-path: inset(50%). Ruff 0.17.6 установлен wheel-пакетом в `.local/lint-venv`, зафиксирован в requirements-dev.txt и required-version; набор E4/E7/E9/F проверяет scripts/tools без переформатирования. `npm run setup:python` воспроизводит подготовку на macOS/Linux с Python 3.10+. Кэш Ruff исключён из Git.

## Целевое project-security-review

Граница инструментов — чтение исходников доверенными локальными линтерами; установка и автоисправления запускаются отдельно от обычного check.
