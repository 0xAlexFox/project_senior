
**Основа под техническое задание для web-сервиса:**

Основная цель: разработка небольшого по объему сервиса по конвертации файлов и предоставления API для этого

**Что должно обязательно присутствовать:**

* Главная страница с двумя вариантами конвертации файлов. Предлагаю jpg => png и docx => pdf (если хотите, то в обе стороны). Эти файлы не сильно много весят и легко обрабатываются (ближайший аналог [https://www.ilovepdf.com/word_to_pdf](https://www.ilovepdf.com/word_to_pdf) Я лично знаю как аналогичные сервисы зарабатывают очень много 🥲)
* Конвертации можно проводить на главной или на отдельных страницах, на ваш выбор
* Страница авторизации
* Страница личного кабинета, в которой будет отображаться уникальный API ключ (детали ниже) и переключатель, который контролирует, сохранять ли сконвертированные файлы в профиле. Если он активен, то файлы сохраняются и доступны из личного кабинета. Если выключен - не сохраняются, но те, что уже в профиле, не удаляются
* В личном кабинете можно изменять личные данные пользователя
* Страница описания API
* Необходим API, по адресу на который можно отправлять файлы и получать ответ от сервера. Эти операции выполняются **только** если к запросу был добавлен API ключ
* Файлы, сконвертированные через API могут сохраняться в профиле пользователя
